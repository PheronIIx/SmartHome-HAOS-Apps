# SmartHome HAOS Apps

Публичный репозиторий **кода приложений** для частного умного дома. Конфигурации домов, секреты и другие персональные данные здесь не хранятся.

## Установка репозитория

Home Assistant → Настройки → Приложения → Магазин приложений → ⋮ → Репозитории:

```
https://github.com/PheronIIx/SmartHome-HAOS-Apps
```

`smarthome-deploy` развивается поэтапно: версия 0.6.0 проверена на HAOS для одного строго ограниченного тестового файла; версия 0.7.0 в PR добавляет точный allowlist, per-file manifest и read-only план многофайловой синхронизации. Полноценная многофайловая установка ещё не реализована.

Описание настройки: [SmartHome Deploy](smarthome-deploy/DOCS.md).

Статус: **0.6.0 — тестовая установка/откат одного JS-файла проверены на HAOS; 0.7.0 — ожидает ревью, CI и отдельной проверки на HAOS.**
