# SmartHome HAOS Apps

Публичный репозиторий приложений Home Assistant OS. Здесь находится **SmartHome Deploy 1.0.0** — инструмент контролируемого обновления разрешённых файлов Home Assistant из приватного репозитория `PheronIIx/SmartHome`.

Исходники конфигурации домов, секреты и персональные данные в этот репозиторий не публикуются.

## Установка

В Home Assistant: **Настройки → Приложения → Магазин приложений → ⋮ → Репозитории**. Добавьте:

```text
https://github.com/PheronIIx/SmartHome-HAOS-Apps
```

Выберите **SmartHome Deploy**. Версия в `smarthome-deploy/config.yaml` — `1.0.0`. Для доступа к приватному SmartHome настройте fine-grained GitHub token с разрешением **Contents: Read-only** только на этот репозиторий, указав его исключительно в настройках приложения. В GitHub и переписку токен не передавайте.

Подробная инструкция, функциональность и ограничения: **[SmartHome Deploy — DOCS.md](smarthome-deploy/DOCS.md)**. [История версий и прежние процедуры](smarthome-deploy/HISTORY.md).

## Что умеет 1.0.0

- **Проверяет** GitHub `main` и сравнивает точный серверный allowlist с локальными файлами HA и установленным per-file манифестом; различает изменения содержимого и форматирования.
- Выполняет фоновую **read-only** проверку при запуске и далее раз в **6 часов**; публикует `/config/.smarthome-deploy/status.json` для агрегатора обновлений HA. Отсутствие данных и ошибки не должны выглядеть как «0 обновлений».
- По ручному запуску, при `enable_multifile_install: true`, разрешает транзакционное **обновление и добавление до пяти `www/*.js`** из точного allowlist. План привязывается к коммиту и контрольным суммам; выполняются повторные проверки, резервирование, атомарная запись, журнал и ручной откат.
- Предоставляет в Ingress кнопки **«Проверить»** и **«Обновить»**, историю и восстановление, диагностику и ссылку **«← К обновлениям»**.

**Ограничения:** установка по умолчанию выключена; автоматическая установка из GitHub, запись YAML/JSON/`.storage`, удаление файлов и перезапись локальных конфликтов не поддерживаются. Дашборд «Сервер» использует Storage-режим, его изменения выполняются через интерфейс HA. Приложение не обновляет само себя: для этого служит штатный менеджер приложений HAOS.

**Доступ:** `panel_admin: true` и HA Ingress — согласованная временная модель. Приложение не проверяет роль администратора независимо при каждом API-вызове; прямой доступ неадминистратора к изменяющим API не подтверждён испытанием. Не считать наличие CSRF или сокрытие кнопок полноценной заменой серверной авторизации.

## Подтверждённое состояние на 22.11.2026

В `main` опубликована версия **1.0.0**. Пользователь подтвердил на реальном HAOS установку двух JS (обновление существующего и добавление нового), проверку архива, пробное восстановление, ручной откат и повторную установку на предшествующей RC-сборке. Это подтверждает соответствующие сценарии, **но не означает, что сборка 1.0.0 отдельно установлена и испытана**. Работа ссылки возврата на HAOS после выпуска 1.0.0 также требует отдельного подтверждения. Для частичного аварийного сбоя и независимой SHA-проверки полного восстановления отдельного доказательства нет.

Обновление приложения на HAOS, любые записи в конфигурацию и испытания на оборудовании выполняются только после отдельного согласования. GitHub Merge сам по себе ничего не развёртывает.
