# SmartHome HAOS Apps

Публичный репозиторий **кода приложений** для частного умного дома. Конфигурации домов, секреты и другие персональные данные здесь не хранятся.

## Установка репозитория

Home Assistant → Настройки → Приложения → Магазин приложений → ⋮ → Репозитории:

```
https://github.com/PheronIIx/SmartHome-HAOS-Apps
```

`smarthome-deploy` развивается поэтапно: 0.6.0 проверена на HAOS для одного строго ограниченного тестового файла; 0.7.0 добавила per-file manifest и read-only план синхронизации; 0.7.1 исправила allowlist и резервирование; 0.7.2 отделяет изменения форматирования от обновлений содержимого. Полноценная многофайловая установка ещё не реализована.

Описание настройки: [SmartHome Deploy](smarthome-deploy/DOCS.md).

Статус: **0.7.1 установлена на HAOS; создание резервной копии и тестовое восстановление 15 файлов подтверждены пользователем. Исправления 0.7.2 ожидают CI и отдельного испытания на HAOS. Многофайловая установка не реализована.**
