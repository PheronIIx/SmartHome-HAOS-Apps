# SmartHome HAOS Apps

Публичный репозиторий **кода приложений** для частного умного дома. Конфигурации домов, секреты и другие персональные данные здесь не хранятся.

## Установка репозитория

Home Assistant → Настройки → Приложения → Магазин приложений → ⋮ → Репозитории:

```
https://github.com/PheronIIx/SmartHome-HAOS-Apps
```

`smarthome-deploy` развивается поэтапно: 0.6.0 проверена на HAOS для одного строго ограниченного тестового файла; 0.7.0 добавила per-file manifest и read-only план синхронизации; 0.7.1 исправляет состав allowlist и правила резервирования. Полноценная многофайловая установка ещё не реализована.

Описание настройки: [SmartHome Deploy](smarthome-deploy/DOCS.md).

Статус: **0.7.0 установлена на HAOS; исправления 0.7.1 проходят CI и ожидают отдельного испытания. Многофайловая установка не реализована.**
