# SmartHome HAOS Apps

Публичный репозиторий **кода приложений** для частного умного дома. Конфигурации домов, секреты и другие персональные данные здесь не хранятся.

## Установка репозитория

Home Assistant → Настройки → Приложения → Магазин приложений → ⋮ → Репозитории:

```
https://github.com/PheronIIx/SmartHome-HAOS-Apps
```

Приложение `smarthome-deploy` пока работает в **режиме только для чтения**: сравнивает управляемые файлы с приватным GitHub, ничего не устанавливает и не изменяет.

Описание настройки: [SmartHome Deploy](smarthome-deploy/DOCS.md).

Статус: **прототип, сборка и запуск на HAOS пока не проверены.**
